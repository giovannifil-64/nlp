# Models hosting

Due to the size of the fine-tuned models (_11.8Gb_ in total), it was not possible to upload them to GitHub (due to the size limit imposed on the repository). They are instead hosted on Hugging Face.

The models are available in the following repositories:
- [`SmolLM-360M`](https://huggingface.co/gvnn/nlp-SmolLM-360M)
- [`SmolLM2-360M`](https://huggingface.co/gvnn/nlp-SmolLM2-360M)

> [!IMPORTANT]
> The models are made available with the same Apache 2.0 license as the original models, while the rest of the code is made available under the MIT license.

The stats for the fine-tuning are available in this folder:
- [Stats for SmolLM-360M](fine_tuning_stats_HuggingFaceTB_SmolLM-360M.json)
- [Stats for SmolLM2-360M](fine_tuning_stats_HuggingFaceTB_SmolLM2-360M.json)
